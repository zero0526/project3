# Mathematical Mechanisms (Cơ chế Toán học)

Nơi hiện thực hóa các công thức trong bài báo.

- **`kkt_solver.py`**: Giải bài toán tối ưu lồi (Convex Optimization) để tìm phân bổ tài nguyên $f^*$ (Công thức 27-31).
- **`energy_model.py`**: Tính toán năng lượng truyền dẫn và tính toán (Công thức 11, 14).
- **`queue_dynamics.py`**: Logic cập nhật hàng đợi $Q(t+1)$ dựa trên luật Lyapunov (Công thức 16).
