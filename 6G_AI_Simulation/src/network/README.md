# Network Physics (Vật lý Mạng)

Mô phỏng tầng giao vận và liên kết.

- **`topology_manager.py`**: Sử dụng `networkx` để load đồ thị, quản lý danh sách Node/Link và tính đường đi ngắn nhất (Shortest Path).
- **`channel_model.py`**: Tính toán các thông số vật lý như băng thông khả dụng, trễ truyền dẫn (Transmission Delay).
