# Source Code (Mã nguồn)

Thư mục chứa toàn bộ logic của hệ thống mô phỏng.

- **`core/`**: Môi trường chính (Environment).
- **`agents/`**: Các thuật toán AI (RL Agents).
- **`network/`**: Mô phỏng vật lý đường truyền.
- **`entities/`**: Định nghĩa Node, Terminal, Task.
- **`mechanisms/`**: Các công thức toán học (Energy, Queue, KKT).
- **`visualization/`**: Code giao diện Dashboard.
